# Font sources

Original, unmodified WOFF2 subsets downloaded from Google Fonts.
Inter: variable weights 300–800, normal. Lora: variable weights 400–700, normal and italic.
Latin and Latin-ext Unicode ranges are preserved from the Google Fonts stylesheet.

Stylesheet: https://fonts.googleapis.com/css2?family=Inter:wght@300..800&family=Lora:ital,wght@0,400..700;1,400..700&display=swap

Licenses: inter-OFL.txt and lora-OFL.txt, from the official google/fonts repository.
